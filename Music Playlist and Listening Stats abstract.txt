Music Playlist and Listening Stats Manager
The Music Playlist and Listening Stats Manager is a Java software application aimed at simplifying and automating music-related recording jobs. Usually dealing with a large volume of songs under the same heading, along with listening records and details. The system is there to provide an application to save the recorded songs as well as playlists so both elements can effectively be managed. The system allows the user to add, edit, search, and display records. Each song is saved with the ID, name, artist, album, genre, and length. New playlists may be created and populated with the available music. A song currently playing may be saved for listening statistics. The system shows the number of times each song is played, as well as how long it's been played, etc.
 The task is made significantly easier and requires minimal work through the reduction in manual work required; not just to store music, but also to manage playlists effectively, and to analyze data on how the application and song information is consumed, and how to make an advanced listening analysis using it more efficiently. The program could be developed into a client and could be a client program working directly and/or as a web service. The system is extensible, and new functions like arranging songs in sorted order, find mostly played songs in a playlist, and other important listening data related, can further develop to be designed so user can analyse their consumption data better and more clearly.
